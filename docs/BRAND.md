# Identidad Calvito

Una C protectora, una cabeza sin cabello y una órbita. Menta e ivory sobre azul
oscuro. Original: `src/renderer/assets/logo-original.png`; interfaz:
`src/renderer/assets/icon.png`; Windows: `build/icon.ico`. `npm run icons`
regenera tamaños y formato.

Generado con la herramienta integrada de imágenes. Prompt final:

> Use case: logo-brand. Create one finished application icon for Calvito Browser,
> a unique open source desktop browser. A memorable geometric abstract C which
> subtly suggests a friendly bald head and a protective orbit. Premium restrained
> vector-like mark, mint green and pale ivory on a deep midnight navy rounded
> square. Centered large bold silhouette, crisp edges, works at 32 pixels.
> Flat colors, no mockup, no lettering, no text, no shadows outside the icon,
> no existing browser logos. Square 1024 by 1024 composition, fill the canvas
> with the dark background; generous but compact icon padding. This is the
> actual final icon asset for a Windows executable.
